# strategy-research

## When to use
Any new strategy, parameter, feature or filter, and any statement of the form "X works".

## Rules
- Register each hypothesis in `docs/hypotheses/` BEFORE any real-data run. No parameter grid may be chosen from real data. No real-data run happens until Gate 1 reports and the owner approves in `docs/approvals.md`.
- Expected effect for every hypothesis is "none". A hypothesis exists to be allowed to fail.
- The variant count K (docs/hypotheses/INDEX.md, generated by `scripts/gen_hypotheses.py`) is what the multiple-testing correction must count. Adding a grid point raises K. A test regenerates the docs and compares, so they cannot drift from the code.
- No LLM in the trading loop. No martingale. Strategy code is pure and deterministic.
- The kill criterion is `docs/kill-criterion.md` and its amendments (append-only). Do not edit the original text.

## Hypothesis template (what each file in docs/hypotheses/ states)
1. Claim, in one sentence, with the contract type and duration.
2. Mechanism: why a random-by-design synthetic index might show this (usually: it will not).
3. Parameters and the finite grid, chosen from convention, not from data.
4. Symbols and the break-even probability from the payout model.
5. Required N from the power table (`docs/power-table.md`, `scripts/power_table.py`) at the corrected alpha.
6. Pass and fail conditions, fixed in advance.

## Instructions
1. Write the strategy as a pure class behind `signals.base.Strategy`; add it to `signals/registry.py`.
2. Run `.venv/bin/python scripts/gen_hypotheses.py` and commit the regenerated docs with the code.
3. Test on simulated data only: determinism, no input mutation, `causality_check`.
4. Correction: Holm across the registered family with K variants; report the uncorrected p only beside the corrected one.
5. Strategy approval for trading is separate: `config/strategies.json` lists approved id and version pairs, and risk rule `strategy_approved` blocks anything else.

## Validation
- `.venv/bin/python -m pytest tests/unit/test_strategies.py -o addopts="" -q` (it includes the regenerate-and-compare check for docs/hypotheses).
- `git diff docs/hypotheses/INDEX.md` shows K changing exactly as intended.

## Worked example: add an RSI period 7 variant
1. Add the grid point in the strategy definition; K goes from 44 to 46 (one more variant for each of the 2 symbols).
2. Regenerate the docs, commit both.
3. Do not look at any real tick. The decision to include period 7 must be justified by convention in the hypothesis file, not by results.
