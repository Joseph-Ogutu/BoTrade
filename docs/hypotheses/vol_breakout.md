# Hypothesis: vol_breakout

Generated by scripts/gen_hypotheses.py from the code. Registered before any real-data run (kill-criterion Amendment 4).

## Claim

A tick move larger than k standard deviations of the preceding moves continues over the next 5 ticks.

## Rule

Standard deviation of the previous lookback tick changes. CALL if the last change exceeds +k sd, PUT if below -k sd. Duration: 5 ticks. Contracts: CALL and PUT only; the signal decides the direction.

## Expected effect

## Falsified if
